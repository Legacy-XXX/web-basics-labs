# Лабораторна робота №1

**Дисципліна:** Основи веб-розробки

## Тема
Система контролю версій **Git** та робота з віддаленими Git-репозиторіями.

## Мета
Навчитися використовувати Git для керування версіями проєктів і освоїти роботу з віддаленими репозиторіями на прикладі **GitHub**.

## Що зроблено
1. Створено локальний репозиторій і перший коміт.
2. Створено гілку `new-feature` і злито її в `main`.
3. Репозиторій підключено до GitHub, зміни відправлено командою `git push`.
4. Гілки `custom-feature` і `clone-feature` злито через pull request.
5. Отримано зміни командами `git fetch` і `git pull`.

## Основні команди
```bash
git init
git add .
git commit -m "message"
git push -u origin main
```
